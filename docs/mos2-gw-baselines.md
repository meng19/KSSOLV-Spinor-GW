# MoS2 GW Regression Baselines

This file records the accepted KSSOLV results for the root-level MoS2
multi-k spinor GW examples. Treat these values as regression baselines when
changing GW/epsilon/sigma code.

Generated from the current scripts on 2026-07-28:

- `test_mos2_222_spinor_gw.m`: multi-k static COHSEX.
- `test_mos2_222_spinor_fullfreq.m`: multi-k full-frequency GW
  baseline added on 2026-08-19.
- `test_mos2_444_spinor_fullfreq.m`: multi-k full-frequency GW.

All energies are in eV. Matrix columns follow `sys.kpts`; matrix rows follow
the requested diagonal bands.

## Regression Usage

Run all accepted cases:

```matlab
run('test_mos2_gw_regression.m')
```

Run only one case:

```matlab
mos2_cases = {'mos2_222_fullfreq_gw'};
run('test_mos2_gw_regression.m')
```

Use CPU for machines without a GPU:

```matlab
mos2_use_gpu = false;
run('test_mos2_gw_regression.m')
```
